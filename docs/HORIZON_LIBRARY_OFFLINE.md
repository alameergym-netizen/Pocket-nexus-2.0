# Persistent offline PC library candidate

Persist only complete counted GAMES replies to Android's app-private no-backup directory using AtomicFile. SHA-256 of the PC UUID isolates filenames without saving addresses, tokens or PINs. Raw local game metadata includes names, IDs, install state and playtime reported by the PC; no separately linked Steam-account library is serialized. Versioned format capped at 8 MiB, 20,000 records and 30 days of age. Invalid or expired data is discarded on access. On explicit auth or compatibility errors, clear memory and disk cache; on transport failure, read the persisted snapshot on the worker thread and label it cached in the UI. No remote actions authorized by cached data. No encrypted cache beyond Android app-private storage, no persistent game artwork, no real offline play. Seven pure format unit tests; device and storage lifecycle validation required. Depends on PR #11.
