# G05 Adaptive reconnect guard
Distinct POOR episodes, not repeated reports, count toward flapping. Sustained deadline is anchored to first POOR after warmup; healthy reports cancel it; unknown status is not treated as healthy. Ignore stale Game activity callbacks and clear timers on stop. Three adaptive reconnects maximum per carried resume budget; manual bitrate reset still resets steps. No new automatic features, codec or bitrate floor changes. This is a conservative engineering guard against unnecessary reconnects, not proof of a fix for actual RP6 frame stutter.
