# Unified Retro catalog candidate

UniversalLibrary now enumerates existing indexes for all remembered readable ROM sources, active first. It uses source-bound HomeItem launch ways and source path labels; same named games can be grouped by existing GameShelf name matching but retain separate launch ways. Cap: 30,000 indexed ROM rows across sources, excluding independently pinned entries. Search uses source-bound active-index fallback plus unified catalog results. Retro pages opened from Search and Library preserve explicit source and can return a Retro play action. Three new unit tests. Sources need one initial scan each; unplugged sources are not newly enumerated. Previously pinned entries can remain visible, but are checked on launch. Existing dedicated Retro screen remains single-root; no migration of artwork, achievement, favorites or emulator IDs; no automatic rescans or stable physical-volume identification. Full CI and RP6 device validation required.
