# Stream-session observation candidate

Observes actual PC-stream connection attempts in Game.java: begin at the first available render surface immediately before conn.start, confirm only on connectionStarted, mark failed on rejected stage/abnormal termination, end on graceful termination or activity stop/destroy. Tickets reject callbacks from superseded attempts. The observer is process-local; it is not proof of remote game exit, not persistent across process death, and not a global session lock. Existing ResumeTicket, recovery, adaptive streaming, controller mappings, profiles, host protocol and actual stream start/stop behavior remain unchanged. A retry is a new observed attempt; no automatic actions are wired. Four pure unit tests plus Android build required. Real RP6/Vibepollo lifecycle testing and UI consumption remain outstanding.
