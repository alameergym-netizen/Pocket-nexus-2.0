# Horizon Home workspace candidate

Adds a ninth, opt-in Home layout to the existing Select cycle, preserving all eight stored layout IDs and defaults. On supported landscape dimensions it allocates distinct grid, selected-game detail and persistent Quick Access regions, with bounded columns and tile size. Smaller dimensions use existing grid geometry. Existing pins, actions, art, widget entry, focus and launch paths retained; explicit edge navigation to details/dock and generation guard for stale focus retries. Home-only layout excluded from non-Home library cycling. Four geometry tests. This is not the final approved visual design: controller/touch navigation, short window clipping, RTL, settings/layout cycling and actual RP6 screenshots require verification. No new permissions or data migration. Independent candidate based on merged #34; #38 combined UI/Windows CI pending.
