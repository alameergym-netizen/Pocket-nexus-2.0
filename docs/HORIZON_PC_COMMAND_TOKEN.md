# G02 explicit PC command handoff
One-time random process-local token, carried by the intended PC Library result / HomeLauncher / HomeActivity / PcView / AppView / ServerHelper nested Game intent or Game fallback. Untagged streams (including ordinary Desktop, USB, shortcut, resume) cannot capture a pending command. Game removes token before resume persistence; ResumeTicket also strips it. Commands remain memory-only and are consumed once after actual connection, with host/app/expiry checks. Three additional tests and revised prior queue tests. Does not establish exactly-once remote execution or automatic profile persistence across reconnects, and does not prevent already sent commands.
