# Console button layout

New default stream Back opens the existing in-stream control menu, Home retains live Xbox Guide down/up. Global Back opens Nexus Control, global Guide opens Quick Resume or radial on hold. Root ConsoleActivity screens use the configured Back-to-Control tap; existing dialogs/panels and B navigation retain priority. Settings > Buttons > Console button layout applies the twelve gesture assignments after confirmation; imported custom preferences are not automatically overwritten. Calibration and M1/M2 remain unchanged. Accessibility must be enabled for system keys that Android does not deliver to the app. No guarantee for firmware-reserved Home, external controllers or non-console activities. Three new unit tests; physical RP6 event capture and real host Guide behavior require validation. The stream uses an existing in-stream menu, not an external Activity that could stop the connection.
