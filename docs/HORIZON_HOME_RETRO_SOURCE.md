# Source-bound Retro Home shortcuts

New RetroActivity items retain the selected root in HomeItem.c, and their Home keys include the source. Existing serialized entries and keys remain unchanged. HomeLauncher resolves a bound source only if still remembered and readable; legacy unbound items are rejected when multiple sources are remembered. Revalidate the source before launch and canonical containment within the system directory. Five unit tests. Old ambiguous pins must be re-pinned; no migration guesses. Other producers of HomeItem may remain legacy-unbound. This does not migrate emulator, artwork, favourites or game history IDs, nor prove physical volume identity. Absolute ES-DE system folders retain their existing semantics. Candidate depends on storage and launch guard changes. Device verification required.
