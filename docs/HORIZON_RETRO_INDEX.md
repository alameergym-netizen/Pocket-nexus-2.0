# Per-source retro scan index

Replace the one shared retro_scan.tsv with per-normalized-root versioned indexes in app-private no-backup storage. AtomicFile replaces a previous file only after bounded serialization; 100,000 rows and 16 MiB maximum per source. Reject wrong-root, corrupt, truncated or trailing data and unsafe relative paths. Canonical containment is checked when restoring cached rows. The existing single-root scan and legacy game identifiers are unchanged. Old TSV is no longer read and a fresh scan is needed once. Forgetting a shortcut removes only its index, never ROM files. Cached listings may be stale and the existing scanner does not guarantee a complete scan if an I/O failure or removal occurs during scanning. No cross-source game identity migration or merged library. Six unit tests; actual removable media and interrupted scans require device testing.
