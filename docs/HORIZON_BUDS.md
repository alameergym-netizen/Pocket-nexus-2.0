# Bluetooth audio diagnostics candidate

Expose a weak reference to the active PC-stream AudioTrack only during renderer start/stop lifecycle. On explicit UI request, read actual route, PCM format, track buffer capacity, cumulative underruns and reported performance mode using API guards. No background polling, addresses, or saved device identifiers. Track buffer capacity is not measured latency. Bluetooth output inventory reports A2DP/SCO/LE and exposed rates/channel counts; name matching cannot authenticate hardware. Optional handoff to installed io.github.librebuds (package verified from upstream build.gradle.kts). Upstream https://github.com/librebuds/librebuds documents GPL-3.0, Android 13+, and FreeBuds 7i basic battery/noise-control support as expected, not hardware-tested. No LibreBuds code copied, no vendor control, no new Bluetooth permissions, no automatic installs. Requires integrated CI and RP6 device verification.
