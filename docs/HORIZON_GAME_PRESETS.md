# Horizon per-game stream presets and diagnostics

This candidate builds on #30. Existing game settings menus gain six explicit, confirm-before-apply presets for resolution/FPS/bitrate. The three values are written atomically in existing per-PC/per-game storage. Frame generation, global configuration and existing reset/customization paths are untouched. Presets are starting points, not link measurements or automatically selected routes. Bitrate overrides apply to every link for that game; existing adaptive logic and explicit resume overrides remain in charge. Device Info shows the last observed local stream attempt, never claims the host game ended. Four preset tests in addition to the four #30 observer tests. Verify actual game menu selection, reset, independent game profiles, Android lifecycle and RP6/Vibepollo before release. No new hardware writes or permissions. This is not the full profile engine or full shell redesign.
